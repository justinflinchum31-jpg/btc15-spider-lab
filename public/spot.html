DATA PROVENANCE

What this page does

Requests only public spot-market price and candle observations through a fixed read-only endpoint on the BTC15 site. The server validates OHLCV shapes and timestamps and only returns completed candles. If the source is down or stale, the interface displays that limitation. It does not collect account details, connect wallets, copy trades, place orders, or turn this historical analysis into trading recommendations.

Visit the BRTI historical replay for the separate archived research dataset.
